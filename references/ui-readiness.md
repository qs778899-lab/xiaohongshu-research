# 页面读取与故障定位

## 拒绝后范围确实改变的恢复

旧审批拒绝不是永久的平台限制。若拒绝原因是混入其他私人页面，用户后来明确确认已保存其他工作、Chrome 只保留研究网站，可以记录这项新的范围证据并进行一次当前状态核对。只在实际返回的窗口、配置和页面均匹配时继续；仍返回其他页面或再次拒绝则停止。不要将相同授权重复表述当作范围变化，也不要要求关闭用户页面作为每次研究的常规前置条件。单标签能力恢复后优先采用单标签绑定。

适用于原生浏览器/CUA路径；不替代既有API和固定研究标签流程。仅按当前工具已公布的API操作。

## 先确定故障层级

持续原生研究使用[原生界面队列](native-queue.md)保存操作结果与具体缺口。同一操作类型连续失败时跨帖子暂停重试；用户恢复或重新绑定后，先核对一次真实可读状态，不能把恢复声明当作动作成功。不要反复要求最小化、前置或重新授权来代替工具故障诊断。重载最多一次的边界按原规则保留。

- 单标签接口返回 Browser is not available：说明该浏览器连接不可用，不等于小红书退出登录。若已有授权的原生研究窗口仍可访问，可按原绑定范围核对；扩大窗口读取仍遵守当前授权。
- 原生窗口能显示登录身份和内容，但动作报 noWindowsAvailable 或工具调用超时：记录为操作通道故障，不把空输出当成内容删除、零评论或账号限制。工具重置后须重读说明、重新绑定原研究窗口、刷新定位。
- xhs_flow.py 的依赖检查针对运行它的解释器。用系统 Python 得到缺少依赖时，检查已验证的项目运行环境；不能因此重装全局依赖、索取新登录，或声称采集逻辑坏了。
- API/run/账号已有 STOP 时保持它。网页恢复不能证明受限API或媒体端点恢复；不得删除STOP或新建会话绕过。

## 已实测的原生窗口恢复

若同一研究窗口内容可读，但点击或滚动反复报告 noWindowsAvailable，且当前菜单明确显示“退出全屏幕”，可在原授权窗口退出全屏一次，再依次核对实际正文、滚动后的新内容和展开后的新回复。2026-11-01 实测：退出全屏后这三类动作均恢复；只能记为有效恢复案例，尚不足断言全屏是全部故障的根因。不要重置账号、关闭其他标签或把恢复一项动作当作其他动作已通过。

提交导航或点击展开后第一次观察可能仍是旧内容或“加载中”。先作为中间状态，利用工具的下一次观察并穿插本地资料审读确认加载结果；不要在新内容尚未返回时重复点击，也不要把一次短暂加载立即记成连续通道失败。最终仍无新内容时才保留 content_loading/no_effect 缺口，正常预算续跑不能清除该缺口。

工具明确提示 Mac 锁定时，保存当前帖子、父楼、已读回复数与下一入口，暂停原生操作，等待用户解锁；继续不依赖界面的原文审读。锁屏不是小红书登录或访问限制，不能据此换登录会话；解锁后刷新索引，确认仍为原研究页面再继续。

## 小截图与动作已执行但回传失败

2026-11-02 实测：同帖文字可读时，截图有时变成倾斜的小窗口图，不能据此判帖子空白或已读完图片。若现有授权覆盖原研究窗口、最新树已核对该窗口且明确提供 `Raise` 动作，可对该窗口执行一次并联合核对文字与清晰完整截图；本次两处实际恢复，另一处仍失败，因此不是通用修复。不要从小图猜坐标。连续两次媒体失败后暂停媒体读取；同页文字仍可在实际核验成功后继续，但不清除媒体缺口，也不反复请用户最小化。

Escape、导航或展开后的捕捉报错可能发生在动作已经执行之后。按现有授权重新获取一次状态，核对真实目标和新内容后决定下一步，不立即重做动作。重新读到搜索卡片只证明文字通道恢复。评论截图按内容重叠续读；页比例可能相对于整窗，固定滚动比例可能跳过短评论区的中间回复。

## 把一次导航拆成三项核验

1. 输入：输入框的实际值必须与本轮查询一致。粘贴后无变化，不直接按回车去搜索旧词；可使用工具支持的setValue，并重新读取确认。
   原生 setValue 未生效时，可在已经核对并聚焦的搜索框内用全选和粘贴，再检查实际值；仍未更新就保留输入故障。不得在不确定焦点时粘贴搜索词。
2. 导航：确认地址及标题指向期望查询或笔记。结果卡片优先从原搜索结果打开，保留实际完整链接，不自己补造xsec参数。
3. 内容：期望笔记标题/正文/作者或结果卡片必须出现在当前HTML内容区域；地址改变但HTML标题仍旧、缺少正文，属于内容未就绪，不能按旧元素继续点击。

点击可能只使离屏元素进入可视区。刷新状态后判断是否真的打开，再定位当前可见控件；截图后重新取得元素索引。一次动作报超时仍可能已经生效，先观察，不立即重复操作。

URL 输入也核对实际值。2026-11-02 实测一次逐字输入丢失冒号并进入搜索引擎；重新聚焦地址栏、全选粘贴、核对完整 URL 后提交恢复。不要把错误落地页或浏览器自动补全的历史地址当作本次站内查询证据。

原生界面索引是当前观察的定位信息，不是稳定元素 ID。长列表展开、导航、重绑句柄或异步加载后，优先在同一调用内获取最新完整树，核对目标文本及其父楼上下文，再使用该次返回的索引点击。点击之后检查新回复是否出现、剩余回复数是否变化；不以“工具没有报错”作为成功证据。若发生点赞等误触，按当前状态撤销并核对恢复，在项目日志中如实记载。

长评论区可将少量确定的展开动作放在一批中，但每一次均从新观察重新定位当前未展开楼层，读取新增回复并保存父楼位置；不能先收集一批数字索引再逐个点击。出现加载中先观察其结果，出现页面切换、无效索引或连续失败则结束该批。重载使旧楼层重新折叠时，先补之前尚未读到的位置，不把已读回复重复计数。完成文字阶段前再核对末页标记及所有已发现折叠；媒体可读性另判。

若坐标滚动报 noWindowsAvailable，但当前授权窗口仍可读，可改用刚观察到的滚动区或 HTML 元素索引进行一次滚动，并检查新内容。不要自行猜测 Retina 缩放比例，也不要在同一错误坐标上反复尝试。ScreenCaptureKit 参数错误与平台风控分开记录；可在原授权范围内重新获取一次 App 状态恢复句柄。工具要求重新获取窗口时，不沿用旧句柄；若最新自动审批明确允许重新获取核验，可按该安全路径执行，成功返回同一研究窗口后继续，不重复索取已有授权。新的状态获取也被拒绝时，停止该路径。

遇暂时空白，利用现有工具的内置等待获取状态与截图，穿插本地已采资料审读后复核同页。没有验证/登录/访问限制提示时，可以对同页重载一次。若仍无正文，保存待恢复断点；后续继续请求先复查原页，不把一次空白固化为永久阻塞。不要无限重载或更换账号。

如果仅本次导航空白，而先前页面可读，可以使用当前已观察的浏览器返回按钮回到原研究页，再通过站内搜索框重新输入本轮查询；要重新核对查询值、结果正文与实际原帖链接。这是单次导航恢复，不是绕过验证或账号限制。只看标题变更不能确认结果已加载。

## 作者链接没有打开时

普通点击作者链接后仍在原帖，先核对当前真实链接与页面状态。若工具支持且该链接的实际上下文菜单提供“在新标签页中打开链接”，可在同一Chrome配置中使用该项，随后选择实际新建标签，核对主页公开UID与原帖作者链接一致，再读取相关历史。2026-11-02实测此路径成功；新标签只保留原帖位置，不解决共享前台争用。菜单中的其他浏览器身份入口不属于此恢复步骤。

主页只按相关主题筛标题，再打开相关记录；标题列表滚动无新增且没有平台结束标记时，保留末条标题和待续原因，不能把无变化当全历史读完。

## 并行任务争用窗口

原生App句柄不等于固定标签页绑定。如果工具提示用户正在修改Chrome，或当前标题/URL已切到非本任务页面，先停止动作，不沿用旧索引，也不读取无关正文。优先用已知目标URL的单标签接口重新绑定；接口不可用时，请用户暂停其他原生Chrome操作并前置研究页。新窗口只隔离页面，不保证两个原生操作者能同时控制不同窗口；账号FIFO锁也不能协调不使用该锁的其他工具。

在当前Mac工具未提供窗口ID、按窗口绑定或仅读标题能力时，不承诺App句柄能锁定另一个Chrome窗口，也不承诺完整界面调用能在读取正文前过滤无关内容。先检查工具元数据是否真的支持这些能力。

用户确认前置后，按现有读取授权核查；若工具自动审批仍拒绝，不反复重试或换脚本绕过，完成不受影响的工作并说明被拒动作和原因。仅在所需范围超出已有授权时再询问具体的一次读取。用户明确批准后仍被自动审批拒绝时，停止同类重试和重复授权提问，报告为工具层阻塞；不能靠修改skill或窗口范围承诺消除该限制。

## 长评论区与证据完整性

- 可访问性树出现 showing A-B of N、链接省略或只返回diff时，保存为部分观察。THE END只证明列表到达底部，不证明工具输出包含所有已加载楼层，更不证明折叠回复已读取。
- 按楼保留真实父评论、问题、作者回复及日期；无真实评论ID标明身份未确定，不以昵称自动跨快照合并。
- 发现直接答案后仍核对相关回复中的限定条件、后续反例和图片。报告分开写已核实答案及剩余覆盖，不把单帖答案包装成全站穷尽。
- 仅把已观察的工具故障和有效恢复方式写进修复记录。正文重新出现是恢复证据，不足证明某一次重置、前置或重载就是根因修复。未能复现定位的第三方工具问题不宣称已修复。


## 长正文被工具截断

完整可访问性树也可能截断单个长文本节点。2026-11-02 实测，一篇正文在句中结束，网页下方仍有数段内容；滚动后树未改变，而截图能够读到后文。不要把该案例的字符数当成通用截断阈值。

- 正文或长评论在句中结束、缺少应有尾段，或与截图不符时，按实际页面逐段滚动并用截图补读，保留段落重叠，直到正文结束与评论入口等明确边界。无新树内容不等于页面没有下文。
- 提取文本时保留同一节点内的多行续文；仅筛选带元素编号的行可能丢掉正文。若输出自身提示省略，按已缓存内容的范围分段读取，避免把输出裁切误判为平台隐藏。
- 记录被截断的位置、截图补读的关键尾段及原帖位置，明确区分原字摘录与人工摘要。已知尾段未补齐时，正文仍待处理；对旧记录发现具体漏段，用该范围的新缺口续读，不笼统撤销全部既有成果。
