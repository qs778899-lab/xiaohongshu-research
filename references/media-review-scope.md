# 静图与视频回执边界

`images` 的 `media_reviewed_keys` 只能登记非视频位置；混入库存 `kind=video` 的键时整张回执拒绝，不部分提交。`video` 任务不能登记非视频位置。

视频帧、已看片段或字幕可按原命令保留 `complete=false` 的观察事件与具体缺口；即便提供视频位置键，也不将整项视频库存变为 `reviewed`。只有明确的 `complete=true` 并通过既有全时间线、片段来源 SHA、评论附件扫描等检查，才能按原流程登记整项视频。

静图分批、`explicit_zero` 和独立字幕审读接口保持原有语义。此补丁不迁移、不降级、不补写旧状态；既有错误记录需另行核实和显式更正。本次未扩展原完整视频核验契约，未新增片段媒体格式或原音真实性检测。
