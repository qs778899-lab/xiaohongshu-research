# 原帖链接的实时核验

保存的笔记编号和原文一致，只证明历史对应关系，不证明地址现在可打开。链接应按同一笔记去重，串行检查原报告的完整 URL，并分别保存地址、时间、实际目标、正文或错误。网页打开不等于手机 App 唤起成功；不虚构分享短链或评论楼层直达地址。

## 精确单帖错误返回

现有有效网页凭据的手动绑定在打开一条已观察链接后，落到 `/404?source=note&noteId=...&errorCode=-510001` 时，可使用 `xhs_note_link_return.py --project P --binding B --observation FAILED_JSON --authorization AUTHORIZATION`。输入是实际保存的 `status=failed`、`requested_url`、`metadata.page/url`，必须和原绑定导航意图一致。其他错误码、额外参数、验证或账号提示均不适用。

该入口只返回原凭据健康帖或同账号、同地址、哈希完整的已有正常正文：同 context、session、CDP page、原生 tab/window，保留全部 STOP。先核原页真实错误文字、无访问限制，已显示账号须匹配；错误页未显示账号时只允许返回公开健康帖，随后必须再次核对原账号和正常正文。结果不明不重放。失败链接永久登记于绑定 `failed_note_links`；不得用此入口重试它或解开原帖 hold。

恢复不登记研究已读、不增加完成数，Codex 应实际阅读返回的正文，再继续其他不同地址。若当前 last_url 没有上述正常正文来源，保留断点，不猜选替代正常页。新访问提示立即执行原账号停止规则。此流程不证明错误原因是删帖或参数失效。

实时核验批次应保留三类：本轮正常打开、实际访问失败、尚未验证。要更换失效地址，须重新发现同帖实际入口并打开验证；不能通过改写参数、借用别帖 token、换账号或网络猜链。

如果平台已从该错误页自动转到精确 `explore?source=404`，使用原账号 identity 守卫后返回。同一尝试若仅元数据检查报 `CURRENT_ERROR_CHANGED` 且未记录导航意图或提交，可用 `--resume-home` 接续一次；需保留原尝试、原失败与现场来源，不能重放未知导航。
